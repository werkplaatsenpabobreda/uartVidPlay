# uartVidPlay

*dependencies*
- hxserial
- hxvlc
- hxwebsockets
- signals

```
haxelib git hxserial https://github.com/werkplaatsenpabobreda/hxserial
haxelib install hxvlc
haxelib install signals
haxelib install hxwebsockets
```

check macosx_ver installed with xcode-tools and set it in project.xml
